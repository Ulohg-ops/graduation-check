# 化材系畢業學分檢核系統

上傳成績單（或畢業審核紀錄表）PDF，依照設定好的畢業門檻規則，自動判斷有沒有符合畢業資格。規則可以依學年度分開設定、在 `/admin` 頁面調整，不用改程式碼。

## 安裝與啟動（Windows）

1. 雙擊 `安裝.bat`（只需要做一次）——會自動建立虛擬環境、安裝套件。需要先裝好 Python，安裝時記得勾選「Add python.exe to PATH」。
2. 之後每次要用，雙擊 `啟動.bat`，瀏覽器會自動開啟 `http://127.0.0.1:8000`。
3. 關閉黑色視窗（或按 Ctrl+C）即可停止系統。

其他系統（Mac/Linux）手動安裝：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

## 主要功能

- **上傳成績單批次檢核**：支援一次上傳多個 PDF（成績單或畢業審核紀錄表），結果頁會分開列出每個人的判定結果，可以用清單快速切換。
- **依學年度設定畢業門檻**：不同入學年度的應修科目表、學分門檻可以分開設定，互不影響。
- **結果匯出**：每份結果可以下載成 PDF（用瀏覽器列印功能）或 CSV。

## 應修科目表管理（`/admin`）

### 科目管理

- 設定畢業總學分、必修學分、核心必修學分、選修學分門檻（後三項選填，留空或填0代表不檢查這個子項）。
  - **核心必修學分**：算的是「分組」科目（核心必選修A/B組、專題必選修這種M選N科目）裡，學生實際被採計的那幾門課學分加總。
- 新增/編輯/刪除科目，設定課號、學分、層級（純顯示分類）、分組（M選N時用）。
- 同一分組的科目，「分組」欄位填一樣的名稱即可，系統會自動判斷「選滿幾門」算通過。

### 分組與學年度設定

- 建立新學年度（可以從既有學年度複製一份規則）、刪除、改名。
- 設定各分組要選滿幾門（預設1門）。

### 備註規則設定

處理應修科目表下方的文字備註，例如「選修學分中至少6學分要CH課號」這種細節規則。兩種類型：

- **純提醒**：只顯示文字，不判斷完成與否（例如「依本校雙主修辦法辦理」這種沒辦法自動判斷的備註）。
- **學分條件**：由「範圍」跟「方向」兩個獨立設定組成：
  - 範圍：**選修學分**（限定在選修學分池內算）／**不限選修**（對整份成績單算，不管是不是已經被算進必修）
  - 方向：**須屬於**（課號前綴或名單裡的課要達到指定學分）／**不可屬於**（不是那些課號前綴的部分要達到指定學分）

  同一段備註如果同時有「須屬於」跟「不可屬於」兩種條件，就開兩條規則、類別填一樣的名稱，結果頁會自動歸在同一段落顯示。

### 規則同步（多台電腦）

每台電腦的規則資料（`rules.yaml`）是各自獨立的，沒有雲端同步。要讓另一台電腦用一樣的規則，可以在「分組與學年度設定」分頁用「匯出規則」下載檔案，再到另一台電腦「匯入規則」上傳——匯入是整份覆蓋，會先自動備份原本的 `rules.yaml.bak`。

## 應修科目表代碼對照（畢業審核紀錄表用）

畢業審核紀錄表 PDF 裡每個項目都有一組5碼代碼，例如 `12203`：

```
1 2 200 3
│ │ │   └─ 第5碼：同一組內的細項/選項編號
│ │ └───── 第3-4碼：中分類
│ └─────── 第2碼：大分類
└───────── 第1碼：固定「1」，代表主系
```

| 開頭 | 大分類 | 說明 |
|---|---|---|
| 10000 | 主系總覽 | 結果頁「應修學分」總結 |
| 11xxx | 共同必修 | 國文、外文、體育、通識、服務學習 |
| 12xxx | 系訂必修 | 系訂必修課、核心必選修、專題必選修 |
| 13xxx | 系訂必選 | 目前這系是空的 |
| 14xxx | 一般選修 | 自由選修學分 |
| 18xxx | 其它學分 | 操行、體育、軍訓、服務學習時數、學習護照 |
| 19xxx | 特殊檢核 | 英文能力門檻等非學分類條件 |

子項「未完成」會一路往上蓋到母項、再蓋到 10000 主系——同一個項目在不同代碼層級重複出現是正常的，不是各自獨立的問題。系統結果頁的「未完成項目」區塊已經濾掉跟系統自己判斷邏輯重複的部分（12xxx、19120）。

## 目前系統沒做的部分

以下這些畢業審核規則有實際存在，但這個系統沒有實作，判定時不會納入考量：

1. **先修課程順序**（例如「先過微積分才能修工程數學」）——只寫在應修科目表的備註文字裡，系統不檢查修課順序，只看成績單上有沒有通過那門課。
2. **非學分類門檻**（操行8科、體育5學期、服務學習2科目、學生學習護照時數）——系統不會自己判斷，只會照搬PDF裡教務處自己的判定結果（結果頁「未完成項目」區塊）。
3. **雙主修、輔系、學程**——沒有支援。
4. **碩班**——沒有支援，目前只處理大學部本系（畢業審核代碼開頭固定為`1`）。
