1. 要做一個可以上傳同學成績單(pdf, jpg, 圖片型 PDF ) 的網頁系統
2. 然後根據畢業要求 顯現出有沒有達到畢業的要求

5. 若可以修改 pdf 檔案的話，我們可以修改部分課程的成績，嘗試讓滿足畢業條件的學生變成不滿足

## 畢業門檻的數字意思
1 1 200 1
│ │ │   └─ 第5碼：同一組內的細項/選項編號（1,2,3... 依序）
│ │ └───── 第3-4碼：中分類（在大分類底下再細分）
│ └─────── 第2碼：大分類
└───────── 第1碼：固定「1」，代表主系（大學部本系）
第2碼＝大分類
代碼開頭	大分類	對應到你們系的東西
10000	主系（頂層總覽）	你在結果頁看到的「應修128學分」總結就是這一層
11xxx	共同必修學分	國文、外文、體育、通識、服務學習
12xxx	系訂必修學分	化材系的必修課（含核心必選修、專題必選修）
13xxx	系訂必選學分	這系目前是空的（應修0）
14xxx	一般選修	自由選修學分
18xxx	其它學分	操行、體育、軍訓、服務學習時數、學習護照
19xxx	特殊檢核	英文能力門檻等非學分類條件
（15xxx～17xxx 沒出現過，應該是留給雙主修/輔系/學程之類、這個系用不到的檢核項目）

第3-4碼＝中分類，第5碼＝細項
以 12xxx（系訂必修）為例，剛好就是：

12000  系訂必修學分（大分類）
 ├─ 12100  一般系訂必修學分（固定必修課，31個課號）
 │   └─ 12101  一般系訂必修學分-A類（只有一組，所以直接等於12100）
 └─ 12200  必修-課程m選n（要「選幾門」的群組必修）
     ├─ 12201  A類 = 核心必選修A組
     ├─ 12202  B類 = 核心必選修B組
     └─ 12203  C類 = 專題必選修
11xxx（共同必修）也是同樣邏輯，只是細項换成「外文的三種修課方式」「核心通識的五大領域」：

11200  共同必修-外文
 ├─ 11201  外文-大一英文
 ├─ 11204  外文-英文系課程
 └─ 11205  外文-第二外語
11320  核心通識課程
 ├─ 11321  人文與思想
 ├─ 11322  自然科學
 ├─ 11323  應用科學
 ├─ 11324  社會思潮與現象
 └─ 11325  其它通識課程
- 規律
    - 子項「未完成」會一路往上蓋到母項、再蓋到 10000 主系——這就是為什麼 10 份樣本裡不管差多少學分，第一行永遠是「尚未通過及格門檻」。所以看到 12101 未完成，12100、12000、10000 一定也都跟著顯示未完成，不是四個獨立的問題，是同一件事往上疊加顯示。

## 還有其他「真實規則」但系統沒做的
以下這些在應修科目表原文或官方PDF裡都有，但我們自己的判定邏輯完全沒實作，之前的對話有各別提過：

1. 先修課程順序（例如「先過微積分才能修工程數學」）——只寫在備註文字，不檢查
2. 選修內容限制（例如「選修至少6學分要是本系CH課程」）——只看總學分數字，不管內容
3. 通識五大領域各修一個——沒有拆到領域細節去檢查
4. 非學分類的門檻（操行8科、體育5學期、服務學習2科目、學生學習護照時數）——完全沒檢查
