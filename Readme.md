# 化材系畢業學分檢核系統

上傳成績單（或畢業審核紀錄表）PDF，依照設定好的門檻規則，自動判斷有沒有符合資格。涵蓋大學部畢業資格、輔系、雙主修、碩博班（碩士班／博士班／工學博士班／逕博）四種身份，各自獨立的一套規則，規則在後台調整、不用改程式碼。

## 安裝與啟動（Windows）

不需要安裝 Python：到 [Releases 頁面](https://github.com/Ulohg-ops/graduation-check/releases/tag/latest) 下載 `graduation-check-windows.zip`，解壓縮後雙擊資料夾裡的 `GraduationCheck.exe` 即可——瀏覽器會自動開啟系統首頁，關掉跳出來的小視窗（或按裡面的「結束系統」）就會停止系統。這個 zip 是 GitHub Actions 每次推到 main 後自動重新打包、覆蓋同一個連結，永遠是最新版。

其他系統（Mac/Linux），或想直接跑原始碼：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

## 主要功能

- **三種上傳頁**：`/` 一般畢業資格、`/minor`（`/double_major` 也導到同一頁）用下拉選單切換輔系／雙主修身份、`/graduate` 碩博班（下拉選入學學年度、再下拉選碩士班／博士班／工學博士班／逕博）。導覽列可以互相切換。
- **上傳成績單批次檢核**：支援一次上傳多個 PDF，結果頁會分開列出每個人的判定結果，可以用清單快速切換。
- **依學年度設定畢業門檻**：大學部、輔系、雙主修、碩博班的規則都是依入學學年度分開設定的，互不影響——碩博班存在獨立的 `graduate_rules.yaml`，學年度清單跟大學部（`rules.yaml`）是分開的兩份。
- **結果匯出**：每份結果可以下載成 PDF（用瀏覽器列印功能）或 CSV。

## 應修科目表管理

分成兩個頁面，上方有切換列：

- **`/admin`**：大學部（科目管理／分組與學年度設定／備註規則設定）
- **`/admin/programs`**：輔系／雙主修／碩士班／博士班／工學博士班／逕博，各自獨立的分頁籤

### 科目管理

- 設定畢業總學分、必修學分、核心必修學分、選修學分門檻（後三項選填，留空或填0代表不檢查這個子項）。
  - **核心必修學分**：算的是「分組」科目（核心必選修A/B組、專題必選修這種M選N科目）裡，學生實際被採計的那幾門課學分加總。
- 新增/編輯/刪除科目，設定課號、學分、層級（純顯示分類）、分組（M選N時用）。
- 同一分組的科目，「分組」欄位填一樣的名稱即可，系統會自動判斷「選滿幾門」算通過。

### 分組與學年度設定

- 建立新學年度（可以從既有學年度複製一份規則）、刪除、改名。
- 設定各分組要選滿幾門（預設1門）。

### 備註規則設定

處理應修科目表下方的文字備註，例如「選修學分中至少6學分要CH課號」這種細節規則。兩種類型：

- **純提醒**：只顯示文字，不判斷完成與否（例如「依本校雙主修辦法辦理」這種沒辦法自動判斷的備註）。
- **學分條件**：由「範圍」跟「方向」兩個獨立設定組成：
  - 範圍：**選修學分**（限定在選修學分池內算）／**不限選修**（對整份成績單算，不管是不是已經被算進必修）
  - 方向：**須屬於**（課號前綴或名單裡的課要達到指定學分）／**不可屬於**（不是那些課號前綴的部分要達到指定學分）

  同一段備註如果同時有「須屬於」跟「不可屬於」兩種條件，就開兩條規則、類別填一樣的名稱，結果頁會自動歸在同一段落顯示。

### 輔系／雙主修

跟大學部共用同一套表單（科目/分組/備註規則），差別只在改的是各自獨立的一份「應修科目表」，不會影響大學部學生的判定，也依入學學年度分開設定。雙主修的預設科目清單是複製自各學年度的「系訂必修」，可以再自行調整。

### 碩士班／博士班／工學博士班／逕博

規則存在獨立的 `graduate_rules.yaml`，頂層一樣依入學學年度分開設定（可以新增/複製/改名/刪除學年度，做法跟大學部一樣），每個學年度底下四個學制各自獨立：總學分、六門課程池（高等輸送現象等）至少通過幾門、化工/材料領域各一門、書報討論／專題研究／產業專題研究要修滿幾學期，還有各自一份六門課程池／領域對照表（哪些課算課程池、算哪個領域）、各自一份「需人工確認項目」（資格考排名、論文口試、SCI論文點數、英文能力等，只在結果頁顯示提醒文字、不影響判定——碩士班沒有博士班才有的資格考/論文點數/英文能力規定，所以不會共用同一份）。及格分數（成績單解析用的數字門檻）是同一學年度四個學制共用。

### 規則同步（多台電腦）

每台電腦的規則資料（`rules.yaml`、`graduate_rules.yaml`）是各自獨立的，沒有雲端同步。大學部/輔系/雙主修的規則（`rules.yaml`）可以在「分組與學年度設定」分頁用「匯出規則」下載、到另一台電腦「匯入規則」上傳——匯入是整份覆蓋，會先自動備份原本的 `rules.yaml.bak`。**碩博班的規則（`graduate_rules.yaml`）目前沒有匯出/匯入功能**，要同步的話得手動複製這個檔案過去。

## 應修科目表代碼對照（畢業審核紀錄表用）

畢業審核紀錄表 PDF 裡每個項目都有一組5碼代碼，例如 `12203`：

```
1 2 200 3
│ │ │   └─ 第5碼：同一組內的細項/選項編號
│ │ └───── 第3-4碼：中分類
│ └─────── 第2碼：大分類
└───────── 第1碼：固定「1」，代表主系
```

| 開頭 | 大分類 | 說明 |
|---|---|---|
| 10000 | 主系總覽 | 結果頁「應修學分」總結 |
| 11xxx | 共同必修 | 國文、外文、體育、通識、服務學習 |
| 12xxx | 系訂必修 | 系訂必修課、核心必選修、專題必選修 |
| 13xxx | 系訂必選 | 目前這系是空的 |
| 14xxx | 一般選修 | 自由選修學分 |
| 18xxx | 其它學分 | 操行、體育、軍訓、服務學習時數、學習護照 |
| 19xxx | 特殊檢核 | 英文能力門檻等非學分類條件 |

子項「未完成」會一路往上蓋到母項、再蓋到 10000 主系——同一個項目在不同代碼層級重複出現是正常的，不是各自獨立的問題。系統結果頁的「未完成項目」區塊已經濾掉跟系統自己判斷邏輯重複的部分（12xxx、19120）。

## 目前系統沒做的部分

以下這些規則有實際存在，但這個系統沒有實作，判定時不會納入考量：

1. **先修課程順序**（例如「先過微積分才能修工程數學」）——只寫在應修科目表的備註文字裡，系統不檢查修課順序，只看成績單上有沒有通過那門課。
2. **非學分類門檻**（操行8科、體育5學期、服務學習2科目、學生學習護照時數）——大學部主系不會自己判斷，只會照搬PDF裡教務處自己的判定結果（結果頁「未完成項目」區塊，且已經納入最終通過/不通過判定）；輔系/雙主修沒有這個對照，教務處在畢業審核紀錄表裡對「輔系-特殊檢核條件」等子規則的判定完全不會反映到系統的結果。
3. **碩博班的資格考、論文口試、SCI論文點數、英文能力**——本來就沒辦法從成績單自動判斷，只會在結果頁列出文字提醒（「需人工確認項目」），不影響通過/不通過的判定。
4. **學程**——沒有支援（跟輔系/雙主修不是同一種東西，目前系統沒有對應的身份）。
